X 日报 Skill

从你已登录的 X 里，把当天真实的高互动帖子连正文带直链捞出来，筛掉噪音，产出一份可读的 HTML 日报。

核心判据：可复用信息密度 > 互动量。互动高的帖子常常是垃圾。
这个 skill 的价值不在「抓得多」，而在「扔得准」。

看真实样例 → GitHub 仓库

它做三件事

  1. 边滚边抓X 是虚拟列表，滚过去的帖子会从 DOM 消失、永久链接一起没。所以必须每滚一屏抓一次，而不是先滚完再抓。
  2. 按可复用价值筛选不是按互动量。优先留有量化数据、给可复现条件、做系统性对比、记录踩坑的帖子。
  3. 产出 HTML 日报并在页面上明说扔掉了什么、样本有多少、以及「这是个性化推荐流不是全网热榜」这条局限。

样例：2026-10-14 实跑，181 条去重样本 → 筛出 35 条（噪音率约 80%）。
依赖 BrowserSkill 与 Python 3。安装与用法见 README。
